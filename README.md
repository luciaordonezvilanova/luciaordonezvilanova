### 👩‍💻 About Me

<img align="right" src="https://i.ibb.co/NgdZ53ZX/LUCIA-AND-TOTORO.png" width="150" alt="Lucia Totoro" />

I am a **Frontend Developer and UX/UI Designer** based in Barcelona. Currently, I lead frontend development and UX/UI design at the **Innovation Unit of Universitat de Vic - UCC**, creating custom internal management tools that streamline complex institutional workflows.

**What makes my approach different:**  
Before moving into tech, I spent **10 years managing administrative and legal procedures**, backed by a degree in **Political Science & Public Management (UAB)**. Having dealt with clunky bureaucratic software firsthand, I know how to analyze business rules, talk to users, and build interfaces that reduce friction and prevent input errors.

### 🐸 RibbID — Real-Time Bioacoustics Desktop Engine
> Native desktop application for real-time amphibian call recognition and digital audio signal processing.

<img align="left" width="180px" src="https://github.com/user-attachments/assets/ec5cb7f2-51e8-4177-8cc0-00db35b57cb8" alt="RibbID preview" style="border-radius: 8px; margin-right: 15px;" />

A bioacoustics application designed to record, analyze, and identify frog and toad vocalizations in real time. It features live microphone capture, WAV stream parsing, and low-latency DSP visualizers (oscilloscope waveform, audio level metering, and real-time FFT frequency spectrograms), backed by an automated species identification engine.

### 🎬 Take One — Mood-Adaptive Movie Recommender
> Context-aware media recommendation tool driven by emotional heuristics and multi-criteria filtering.

<img align="left" width="200px" src="https://i.postimg.cc/JnGS7s8z/Captura-de-pantalla-2025-11-19-a-las-22-32-53.png" alt="Take One preview" style="border-radius: 8px; margin-right: 15px;" />

An intelligent movie recommendation tool designed to suggest films tailored to the user's emotional state. Built under **SOLID design principles** to keep filtering heuristics modular and decoupled from the UI. Implements global state management via the **Provider Pattern** (React Context API) to eliminate prop drilling, wrapped in a responsive movie-poster interface.

### 💳 Personal Budget Assistant
> Financial management dashboard featuring transactional CRUD operations, budget limits, and analytics.

<img align="left" width="180px" src="https://i.postimg.cc/ryghsZYC/screencapture-personal-budget-assistant-vercel-app-2024-10-29-11-29-56.png" alt="Personal Budget Assistant" style="border-radius: 8px; margin-right: 15px;" />

Developed during the **NUWE & CaixaBank Tech Hackathon**, this application helps users track and visualize expenses in real time. It features a complete CRUD system for financial transactions, dynamic threshold alerts, reactive state management using Nanostores, interactive charting with Recharts, and automated CSV data export.
